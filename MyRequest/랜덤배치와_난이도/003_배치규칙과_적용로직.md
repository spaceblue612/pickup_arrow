# 003 — 배치 규칙과 적용 로직

작성일: 2026-10-29  
참조: [002 필수 속성](002_우선적용할_필수속성.md)  
상태: 기존 생성기를 활용해 보강할 규칙의 제안. 아래 규칙을 모두 구현했다는 뜻은 아닙니다.

## 1. 수치와 규칙의 역할

수치는 원하는 결과의 양과 구성을 지정합니다. 규칙은 그 결과를 만드는 배치 방법입니다. 예를 들어 '긴 화살 20%'는 수치이고 '긴 화살로 짧은 화살의 묶음을 감싸기'는 규칙입니다.

규칙에는 안정적인 ID를 붙입니다. 후속 문서에서 규칙을 수정할 때 ID와 변경 이유를 기록하고, 생성 결과에는 적용 규칙과 확인 결과를 남길 수 있게 합니다.

## 2. 우선 적용할 규칙

| ID | 규칙 | 배치 방법 | 확인 방법 |
|---|---|---|---|
| R01 | **원하는 크기 구성을 먼저 확보하기** | 크기별 목표 비중에서 부족한 종류를 우선 선택하고 자리·점유량을 확보 | 신규 화살의 크기별 비중 비교 |
| R02 | **선행 연결을 만들며 배치하기** | 다른 화살의 출구 직선에 몸체 일부를 놓아 먼저 제거할 관계를 구성. 순환 관계가 되면 거절 | 방해 관계와 실제 제거 순서 확인 |
| R03 | **연결을 여러 곳에 분산하기** | 최장 연결 하나를 만든 후에도 목표 참여 비중까지 다른 묶음에 연결 구성 | 긴 연결 참여 화살의 분포 강조 |
| R04 | **긴 화살로 짧은 화살 묶음을 감싸기** | 짧은 화살 주변을 꺾인 긴 몸체로 두르며, 묶음 일부의 출구 직선을 가로지르게 배치 | 감싼 모양과 실제 차단 관계를 각각 확인 |
| R05 | **빈 곳을 보충하되 풀이 구조를 지키기** | 남은 점유량과 크기 비중에 맞는 화살을 추가하고 전체 관계를 재검사 | 채우기 결과와 시작 선택지·연결 결과 재확인 |

R01~R03은 목표 구성과 관계를 만드는 기본 규칙입니다. R04는 사용자가 제시한 우선 실험 패턴이며 모든 배치에서 강제할 조건은 아닙니다. R05는 마지막 빈칸 채우기가 이미 만든 관계를 무너뜨리지 않게 합니다.

## 3. 감싸기 규칙의 구체적인 의미

긴 몸체가 주변에 있다는 것만으로 짧은 화살이 막히지는 않습니다. 현재 게임은 머리 앞의 직선으로 탈출하므로, 실제 방해를 만들려면 그 직선과 긴 몸체가 만나야 합니다.

R04의 첫 실험은 다음 범위로 제한합니다.

1. 짧은 화살이 모인 부분을 정합니다.
2. 주변에 여유가 있으면 긴 화살을 ㄴ자·ㄷ자처럼 돌아가게 만듭니다. 완전히 폐곡선으로 둘러쌀 필요는 없습니다.
3. 긴 몸체가 짧은 화살 일부의 출구 직선을 막게 합니다.
4. 긴 화살 자신의 출구와 다른 화살과의 관계를 검사합니다. 서로 영원히 막는 순환 구조는 거절합니다.
5. 긴 화살을 뺐을 때 새로 열리는 화살을 확인합니다. 다른 방해가 남아 있으면 곧바로 열리지 않을 수도 있습니다.

초기에는 감싸기 강도·감싸는 거리 등 세부 입력을 만들지 않습니다. 가능할 때 우선 시도하는 규칙으로 두고 성공한 사례를 보며 세분화합니다. 작거나 좁은 영역에서 적용할 수 없으면 다른 규칙으로 배치하고 적용하지 못했다는 결과를 남깁니다.

## 4. 배치 흐름

1. **공간 확인:** 생성 범위의 빈칸·금지 칸·기존 점유를 확인합니다.
2. **구성 준비:** 목표 점유량과 크기 비중으로 필요한 크기들을 정합니다. 긴 화살이 들어갈 공간을 먼저 확보합니다.
3. **관계 구성:** 짧은 묶음, 감싸는 긴 화살, 선행 연결을 함께 조합합니다. 어느 크기를 먼저 실제 배치할지는 규칙에 따릅니다.
4. **목표 확인과 보충:** 크기·꺾임·점유 부족분을 채우면서 시작 선택지와 연결 목표를 재확인합니다.
5. **전체 검증:** 전체 보드의 겹침·금지 칸·몸체 규칙·클리어 가능성을 공용 코어로 검사합니다.
6. **후보 표시:** 목표와 실제, 미달 원인을 보여줍니다. 사용자가 적용하면 한 번의 실행 취소로 되돌릴 수 있게 합니다.

역순 배치·풀이 가능성을 유지하는 기존 생성 방식을 활용하되, 이미 있는 수동 화살까지 포함해 검사합니다. 영역 안에서만 관계를 검사하고 성공으로 처리하지 않습니다. 목표를 만족하지 못해도 기존 화살이나 입력한 목표를 자동으로 바꾸지 않습니다.

## 5. 툴에서 규칙이 효과적인지 확인하기

각 규칙은 적용했다고 표시하는 것과 효과가 확인되는 것을 구분합니다.

- R01: 목표 크기 구성이 실제로 가까워졌는지 봅니다.
- R02·R03: 관계 강조로 연결 길이와 참여 범위를 보고 풀이를 재생합니다.
- R04: 긴 화살이 막는 짧은 화살을 강조하고, 실제 제거 전후 개방을 비교합니다.
- R05: 채우기 전후에 시작 선택지나 연결 목표가 달라졌는지 비교합니다.

같은 보드·기존 배치·채우기 목표로 특정 규칙을 사용한 결과와 사용하지 않은 결과를 비교하면 효과를 판단하기 쉽습니다. 규칙을 켜고 끄면 난수 소비 순서도 달라질 수 있으므로 같은 시드만으로 완전히 같은 조건의 결과가 된다고 가정하지 않습니다. 첫 검증은 생성 결과 비교와 수동 플레이로 충분하며, 체감 평가가 쌓이면 속성 범위를 보강합니다.

## 6. 다음 보강 기록에 남길 내용

새 규칙이나 속성을 추가할 때는 해결하려는 실제 배치 문제, 적용 전후 예시, 바꾼 수치와 규칙 ID, 목표와 실제 결과를 다음 번호 문서에 기록합니다. 기존 문서는 덮어쓰지 않습니다.
