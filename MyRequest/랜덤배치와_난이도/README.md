## 기록 방식

- 번호는 시간순으로 계속 증가시키며 재사용하지 않습니다.
- 내용 보강·판단 변경은 다음 번호의 새 문서로 남깁니다. 이전 문서의 결론을 새 결론으로 덮어쓰지 않습니다.
- 번호 없는 현재 적용기준표는 회의 결정에 따라 갱신합니다. 조사 후보를 자동으로 추가하지 않습니다. 결정의 배경은 번호 문서로 남기고 근거 링크를 연결합니다.
- 새 문서에는 작성일, 참조한 이전 번호, 달라진 내용, 제안인지 확정인지 구현되었는지를 기록합니다.
- 001~004는 조사와 제안 기록입니다. 회의에서 채택하기 전에는 구현 기준으로 사용하지 않습니다.
- 기존 원본 [자동 배치 조사](../자동배치_채우기와_난이도_속성_조사.md)는 원래 위치에도 유지합니다.

다음 조사·회의 기록 번호는 **005**입니다.
