# 부분 생성 — 양과 보존 기준

상태: 부분 생성·영역 지정·퍼센트와 개수·맞물림과 연쇄 제어·맵 수치 분석을 필수 요구사항으로 확인 / 제어 범위와 세부 의미는 검토 중

기획 기준: [2단계 기획 문서](stage_editor_design.md).

화면 제안: [부분 생성 목업 v0.4](wireframes/05-partial-generation-v04.png) / [SVG 원본](wireframes/05-partial-generation-v04.svg).

## 1. 사용자 요구사항

- 기존 배치를 유지하고 그다음 부분을 랜덤 생성하거나 직접 배치하는 작업을 주로 사용합니다.
- 전체 보드를 처음부터 다시 생성하는 방식만으로 구성하지 않습니다.
- 사용자가 랜덤 생성할 양을 정할 수 있어야 합니다. 퍼센트와 개수를 기본으로 지원합니다.
- 선택한 영역 안에서 개수 또는 퍼센트에 맞게 추가 생성할 수 있어야 합니다.
- 후보의 작업 방향에 따라 맞물림·연쇄·풀이 가능 개수 같은 제약을 설정할 수 있어야 합니다.
- 현재 맵을 수치로 분석하고 밸런싱 결과를 편집기에서 확인할 수 있어야 합니다.
- ‘풀이 가능 개수’는 현재 제거 가능한 화살표 수로 확인했습니다. 전체 맵 목표와 영역별 제약을 관리하는 방식은 제안 중입니다.
- 후보 저장과 생성은 별도입니다. 추가 생성만으로 새 후보나 저장 이력을 자동 생성하지 않습니다.

## 2. 생성량의 기본 기준 제안

두 입력을 별도 생성 모드로 구분하고, 한 번 실행할 때 주된 종료 기준 하나를 선택합니다. 첫 화면부터 두 목표를 동시에 강제하지 않습니다.

| 모드 | 입력의 의미 | 예시 |
|---|---|---|
| 선택 범위의 점유율까지 채우기 | 선택 범위의 사용 가능한 칸 중 기존 배치를 포함하여 화살표가 차지할 최종 비율 | 선택 영역이 현재 30% → 목표 50%라면 그 영역의 약 20%만 더 채움 |
| 화살표 개수 추가 | 이번 실행에서 실제로 추가할 화살표 수 | 현재 12개 → 5개 추가: 결과는 총 17개 |

퍼센트는 화살표 개수나 진행률이 아닌 **점유 칸 수**입니다. 화살표 한 개가 여러 칸을 차지하므로 개수와 점유율은 서로 다른 기준입니다. 보드 전체를 선택하면 기존의 전체 보드 기준을 사용하고, 특정 영역을 선택하면 그 안의 배치 가능한 칸을 기준으로 제안합니다. 배치 금지 칸은 제외하며, 선택 영역에 걸친 기존 화살표는 영역 안에 있는 몸체 칸만 점유율에 포함합니다.

선택 영역이 전체 보드의 1/4이라면 ‘영역을 60%까지’는 그 영역의 점유율 목표입니다. 전체 맵을 60%까지 채우거나 남은 빈칸의 60%를 추가한다는 의미로 바꾸지 않습니다. 화면에 선택 영역의 비율과 전체 맵의 비율을 각각 표시합니다.

개수는 기본 화살표·보충 화살표를 합친 실제 추가 수입니다. ‘5개 추가’에서 보충 화살표를 별도로 더 넣어 결과가 5개를 넘게 만들지 않습니다. 점유율 모드에서는 추가 수가 화살표 길이에 따라 달라집니다.

화면에는 실행 전후를 비교할 수 있게 현재 화살표 수·점유 칸·점유율, 선택한 목표, 생성 후 실제 값을 표시합니다. 점유율은 정수 칸으로 환산해야 하므로 목표 퍼센트와 달성한 칸 수·실제 비율을 함께 표시합니다. 칸 수 환산 규칙은 구현 계약에서 고정합니다.

목표가 현재보다 낮으면 기존 화살표를 삭제하지 않습니다. 이미 목표를 달성한 상태라고 알리고 추가하지 않습니다. 목표와 같은 경우도 생성할 필요가 없는 상태로 구분합니다.

## 3. 보존과 결과 반영 제안

- 기본 부분 생성은 기존 화살표의 ID·위치·방향·몸체와 보드의 배치 금지 영역을 유지합니다.
- 새 화살표는 허용된 빈칸에 추가합니다. 기존 것을 옮기거나 방향을 다시 배정하여 목표를 맞추지 않습니다.
- 영역을 지정하면 새 화살표의 머리와 몸체 전체를 선택 영역 안에 배치하는 기준으로 제안합니다. 기존에 영역 경계에 걸쳐 있는 화살표는 잘라내거나 이동하지 않습니다.
- 생성 영역의 경계는 게임 규칙의 벽이 아닙니다. 영역 밖 화살표와의 막힘 관계도 실제 전체 보드에서 판정합니다.
- 추가 전 기존 보드와, 추가 후 전체 보드를 공용 규칙으로 검사합니다. 추가분만 따로 풀리는 것으로 전체 해결 가능성을 판단하지 않습니다.
- 생성 미리보기에서 기존 화살표와 추가 예정 화살표를 구분합니다. ‘적용 / 다시 생성 / 취소’를 제공하는 방식을 제안합니다.
- 적용은 현재 작업 보드만 변경합니다. 후보에 남기려면 별도로 저장하며, 후보 분기는 기존에 확정한 저장 기준을 따릅니다.
- 요청한 양을 채우지 못했으면 실제 추가량과 미달 상태를 표시합니다. 목표를 달성한 성공으로 표시하거나 기존 배치를 변경하지 않습니다.
- 실패·취소 시 기존 작업을 보존합니다. 목표 미달 결과를 일부 적용할지의 정책은 후속 설계에서 확정합니다.

초안의 중간 상태 저장과 생성 결과의 규칙 검사는 별도로 둡니다. 예를 들어 현재 규칙에서 기존 화살표만으로 제거 불가능한 순환이 생겼다면, 화살표를 추가하는 것만으로 그 순환이 해소되지는 않습니다. 이런 경우에는 기존 배치 수정이 필요함을 설명해야 합니다.

## 4. 옵션을 나누는 기준

| 축 | 역할 | 현재 상태 |
|---|---|---|
| 얼마나 생성하는가 | 선택 범위의 목표 점유율 또는 추가 화살표 수 | 기본 필수 / 위 의미로 제안 |
| 어디에 생성하는가 | 전체 빈칸 또는 사용자가 지정한 영역 | 필수로 확인 / 영역 지정 조작은 후속 설계 |
| 어떤 화살표를 만드는가 | 새 화살표의 길이·굴곡·방향 | 기존 옵션을 출발점으로 후속 토론 |
| 기존 맵과 어떻게 맞물리는가 | 맞물림·연쇄·풀이 가능 개수 제어 | 필수로 확인 / 지표 의미와 적용 범위는 확인 중 |
| 공간에 어떻게 분포시키는가 | 중심·지역별 밀도 등 형상 특성 | 기존 지표를 출발점으로 후속 토론 |
| 생성 결과를 어떻게 재현하는가 | seed와 생성 조건 | 기존 기능 활용, 저장 항목은 후속 설계 |

보존·겹침·범위 같은 규칙과 원하는 모양·난이도 목표를 구분합니다. 점진적으로 만드는 중간 단계에서 최종 맵 전체의 형상·난이도 목표를 일괄 강제할지는 별도로 설계해야 합니다.

길이 조건은 새로 추가하는 화살표에 적용하고 이미 있는 화살표를 자동 수정하지 않는 방향을 제안합니다. 새 화살표 길이 제한과 보충 화살표의 역할도 실제 추가 수 기준에 맞게 정리합니다.

‘연결’은 서로 다른 화살표의 몸체를 합치거나 겹치게 한다는 뜻으로 해석하지 않습니다. 사용자는 실제 맞물림·연쇄 등의 제어가 밸런싱의 핵심이라고 설명했습니다. 생성량만 맞추는 것으로 이 요구를 완료 처리하지 않습니다.

생성할 위치와 난이도를 판정하는 범위를 구분합니다. 기본 관리안은 전체 맵의 완성 목표를 두고, 생성 위치는 영역으로 제한하며, 영역별 제약은 필요할 때 추가하는 방식입니다. 영역 밖 화살표를 제거했다고 가정하고 부분 맵만 따로 판정하지 않습니다.

상세 제약과 현재 맵의 수치 분석: [밸런싱 제어와 맵 분석](stage_editor_balancing.md).

## 5. 현행 구현과 이행

- 현재 `ArrowPlacement.generate()`와 `DependencyTargeting.select()`에는 기존 화살표를 받아 유지하는 입력이 없습니다.
- 현재 `arrow_count`는 기본 화살표 수이며, 목표 빈칸 비율을 맞추는 보충 화살표 등이 별도로 추가될 수 있습니다. 새 화면의 ‘추가 개수’와 그대로 대응시키지 않습니다.
- 현재 `target_empty_ratio`와 생성 지표는 배치 가능한 칸을 기준으로 합니다. 새 점유율 표시와 기존 빈칸 비율의 관계를 명시적으로 변환합니다.
- 일부 생성 경로는 화살표 방향을 다시 배정합니다. 부분 생성에서는 기존 화살표를 이 처리의 수정 대상으로 넣지 않아야 합니다.
- 기존 영역을 단순히 `blocked_cells`로 바꾸는 것만으로 기존 화살표의 막힘 관계를 표현할 수 없습니다. 기존·신규 화살표를 함께 판정해야 합니다.
- 부분 생성·영역 제한·맞물림과 연쇄 제어·분석은 4단계의 코어 확장에 포함하고, 편집·영역 선택·저장과 연결되는 완성 흐름은 5단계에서 검증합니다. 현재 2단계에서는 기준과 목업을 정합니다.

후속 구현의 필수 검증은 기존 배치 불변, 정확한 추가 개수, 영역 안 점유율 계산, 빈 보드에서 시작, 반복 추가, 영역 밖 배치 방지, 조건 미달·취소 시 작업 보존, 합친 보드의 풀이 일치성, 제약 목표와 실측값의 구분입니다.
