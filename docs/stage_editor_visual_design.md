# 제작 도구 시각 디자인

상태: Discord 색상 기반 실제 앱 구현 / 사용자 피드백으로 보드 중심 밀집 배치 적용. 아래 v0.9·v0.10 설명은 초기 정적 디자인 시안의 기록입니다.

## 최신 실제 화면 — 2026-10-20

현재 기준은 [작업 화면](design/arrow-editor-compact-workspace.png), [맵 조건 상세 창](design/arrow-editor-compact-intent.png)입니다. Electron 앱에서 편집·저장·Godot 분석으로 검증한 실제 화면이며 아래 정적 시안과 구분합니다.

사용자는 정보·버튼의 여백으로 보드가 작아지는 문제, 우측 인스펙터가 아래로 밀리는 문제, 맵 조건 패널이 정보에 비해 너무 큰 문제를 지적했습니다. 새 테마 없이 기존 색상은 유지하고 버튼은 약 29px, 패널은 5~8px 모서리와 작은 여백으로 조정했습니다. 보드의 360px 높이 제한을 제거하고 화면의 남은 영역을 배정했습니다.

현재 스테이지 인스펙터를 우측 첫 패널로 배치하고 개수·칸 점유율을 보강했습니다. 조건은 세 줄 요약으로 통합하고 설명·목표 설정·영역 선택은 필요할 때 상세 창에서 조회합니다. 후보·이력은 기본 접힘입니다. 이 조정은 기능 와이어프레임으로 되돌린 것이 아니라 제작 작업의 정보 밀도와 사용 공간을 개선한 것입니다.

1100×740·1280×800·1680×1080·1920×1080에서 페이지 넘침, 인스펙터 위치, 요약 가시성, 보드 좌표 입력, 상세 창 배치를 실제 앱으로 검증했습니다. 게임 규칙·생성·저장 계약은 이번 화면 조정에서 바꾸지 않았습니다.

## 유지한 기능 구성

- 왼쪽 스테이지 1~N 목록과 순번·ID, 검색·추가·복제·순서 변경 진입점.
- 중앙 보드와 직접 배치·영역·부분 생성·관계 보기, 후보·버전 이력.
- 오른쪽 풀이 가능 수·연쇄·영역 개방의 현재 값과 목표 요약. 빈도·커버리지가 미설정이면 그대로 표시.
- 상세 설정 팝업과 주요 전환점 분석. 맵 조건·현재 상태·풀이 경로별 결과를 구분.

## Discord 지침의 적용

기본 바탕은 `#0a0d3a`, 카드·입력은 `#1e2353`, 선택 상태와 일반 동작은 `#5865f2`입니다. 저장에만 `#35ed7e`와 검정 글자를 사용하고, `#ec48bd`는 분위기 그라데이션에 제한적으로 사용합니다. 제목은 굵은 위계, 조작은 12~16px 모서리, 큰 패널은 둥근 모서리로 구성합니다.

문서는 마케팅 페이지의 분석이므로 제작 도구에 맞춘 조정이 있습니다. 82px 홍보 제목이나 3D 캐릭터를 그대로 넣지 않고 보드와 핵심 수치를 우선합니다. 장시간 편집을 위해 움직이는 배경은 정적인 그라데이션으로 적용했습니다. 작은 글자의 대비를 위해 그라데이션을 인디고와 섞어 어둡게 하고, 구분선에는 흰색 투명도를 사용합니다. 초록색을 일반 상태나 화살표 색상에 사용하지 않습니다.

전용 ABC Ginto·ggsans, Figma 전용 글꼴과 문서가 권하는 대체 웹폰트 파일은 로컬에 없습니다. 외부 다운로드 없이 시스템의 Noto Sans CJK KR 등을 사용합니다. 전용 글꼴과 동일하게 렌더링했다고 표시하지 않으며, 정식 폰트 선정·동봉은 별도 확인 대상입니다.

Figma 시안은 흑백 프레임·라일락 조건 패널·알약형 버튼으로 구성했습니다. 이 시안은 그 외관을 비교하기 위해 유지하며, 최신 Discord 시안에 해당 색상이나 버튼 형태를 혼합하지 않습니다.

## 동작과 검증 범위

로컬 HTML/CSS 시안이며 Electron·React 앱을 구현한 것이 아닙니다. 실제 동작은 예시 스테이지 검색, 작업/분석 전환, 상세 설정 팝업 열기·닫기 및 항목 선택, 관계 표시, 검증된 스냅샷 선택뿐입니다. 나머지 조작은 디자인 예시 안내만 표시하고 맵이나 파일을 변경하지 않습니다. 상세 입력은 읽기 전용입니다.

보드는 [공용 Godot 코어로 검증한 예시](stage_editor_difficulty_profile.md#5-검증한-작은-예시와-한계)의 스냅샷을 표시하며 JavaScript에 충돌·생성·제거 규칙을 재구현하지 않습니다. 두 시안은 같은 스냅샷 표시 스크립트를 공유합니다. 스테이지·후보·버전 표시는 여전히 모형입니다.

추가 화면: [Discord 설정 팝업](design/arrow-editor-v10-profile.png), [Discord 분석](design/arrow-editor-v10-analysis.png). 이 외관을 실제 앱의 구현 기준으로 사용하되 미정인 기능·데이터 계약은 별도로 확정합니다.

검증 기록: 두 시안 모두 브라우저 창 1280×1000, 1680×1080, 1920×1200에서 가로 넘침 없이 세 조건 수치가 스크롤 전에 보이는지 확인했습니다. 예시 검색·빈 결과·팝업 항목 전환·닫기·작업/분석 전환·연결 표시와 0/2/3 제거 시점의 검증 수치, 예시 저장 안내가 원본 스냅샷을 변경하지 않는 것도 확인했습니다. JavaScript 구문 검사와 문서 링크 검사를 수행했습니다. 게임 코드 변경은 없어 게임플레이 회귀 스위트는 이번 디자인 변경에서 다시 실행하지 않았습니다.
